# Processamento de Linguagem Natural (PLN)

Aulas, laboratórios e avaliações da disciplina de PLN (1º semestre de 2026). O conteúdo cobre tokenização, normalização e vetorização, engenharia de atributos, classificadores (regressão logística, Naive Bayes e SVM), clusterização com K-Means, Word2Vec, SBERT e LDA. Usa notebooks Jupyter e fluxos do Orange.
