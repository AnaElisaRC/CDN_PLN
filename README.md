🧠 Processamento de Linguagem Natural (PLN)

Este repositório reúne as aulas, laboratórios e avaliações da disciplina de Processamento de Linguagem Natural (PLN) do curso de Tecnologia em Ciência de Dados para Negócios da FATEC Votorantim (1º semestre de 2026). 

O conteúdo cobre desde tokenização, normalização, vetorização e engenharia de atributos até modelos classificadores (Regressão Logística, Naive Bayes e SVM), clusterização com K-Means, embeddings avançados (Word2Vec e SBERT) e modelagem de tópicos com LDA, utilizando notebooks Jupyter e fluxos interativos no Orange.
